```python
"""
```

**Что это?**  
Это **многострочный комментарий** (документация модуля). Он висит в самом верху файла и описывает, что делает программа.

**Правильно ли сделано?**  
Да! Это хороший тон. Но мы дополним его позже, когда код разрастется.

#### 2. Список задач (коллекция)

```python
collection = ["создать версию 1", "попить кофе"]
```

**Что это?**  
Переменная `collection` — это **список (list)**. В нем уже лежат две задачи для примера.

**Почему список, а не что-то другое?**  
Список идеально подходит для хранения **упорядоченных данных**, которые мы будем добавлять и просматривать. Мы можем использовать `.append()` для добавления новых элементов.

**Что можно улучшить?**  
Пока ничего. Это база. Работаем дальше.

#### 4. Бесконечный цикл

```python
while(True):
```

**Что это?**  
**Вечный цикл**. Программа будет работать, пока мы сами не выйдем (через `break`).

**Важно!** В Python скобки вокруг `True` не обязательны. Можно писать `while True:`. Но вариант с `(True)` тоже работает.

#### 5. Вывод меню

```python
print("1 - добавить задачу | 2 - просмотреть все задачи | 3 - выход из приложения")
```

**Что это?**  
Подсказка пользователю, какие действия доступны.

**Проблема:** Строка слишком длинная и выглядит неаккуратно. Мы исправим это в версии 0.0.3.

#### 6. Ввод выбора пользователя

```python
choice_user = input("Выберите действие: ")
```

**Что это?**  
Функция `input()` всегда возвращает **строку (str)**. Даже если пользователь ввел цифру "1", это строка `"1"`, а не число `1`.

**Важно!** Обратите внимание: `choice_user` хранит **строку**. Поэтому в `match` мы сравниваем со строками: `"1"`, `"2"`, `"3"`.

---

#### 7. Конструкция match (аналог switch/case)

```python
match choice_user:
    case"1":
        task = input("Дайте название задаче: ")
        collection.append(task)
    case"2":
        print(collection)
    case "3":
        print("Досвидания!")
        break
    case _:
        print("Такого пункта нет в меню!")
```

##### case "1" — Добавление задачи

```python
case"1":
    task = input("Дайте название задаче: ")
    collection.append(task)
```

**Что происходит:**
1. Запрашиваем у пользователя название задачи и сохраняем в переменную `task`.
2. Метод `.append()` добавляет эту строку в конец списка `collection`.

**Ошибка:** После `case` нет пробела перед кавычкой (`case"1"`). Так писать **можно**, но **некрасиво**. Лучше писать `case "1":` (с пробелом).

---

##### case "2" — Просмотр всех задач

```python
case "2":
    print(collection)
```

**Что происходит:**  
Программа выводит весь список целиком.

**Проблема:**  
Это неудобно. Список выводится в квадратных скобках с кавычками, как массив.  
Пример вывода:  
`['создать версию 1', 'попить кофе']`

**Как должно быть:**  
Каждая задача на новой строке, с номером и, возможно, красивым оформлением. Это мы сделаем в версии 0.0.3.

---

##### case "3" — Выход из приложения

```python
case "3":
    print("До свидания!")
    break
```

**Что происходит:**
1. Выводится прощальное сообщение.
2. `break` — команда, которая **прерывает** выполнение вечного цикла `while`. Программа завершается.


---

##### case _ — Обработка неизвестного пункта

```python
case _:
    print("Такого пункта нет в меню!")
```

**Что это?**  
`case _` срабатывает, если `choice_user` не совпал ни с одним из предыдущих вариантов. Это аналог `else` в конструкции `if`.

**Важно!** `case _` обязательно должен быть **последним** в `match`. Это страховка от дурака.
