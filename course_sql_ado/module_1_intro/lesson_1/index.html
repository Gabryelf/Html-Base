Введение в теорию баз данных. Установка и архитектура MS SQL Server

🎯 Цель урока: Понять, что такое СУБД и реляционная модель, установить SQL Server и SSMS, выполнить первое подключение.

📖 1. Что такое база данных и СУБД

База данных (БД) — это структурированный набор данных, хранящихся в электронном виде. СУБД (Система управления базами данных) — это программное обеспечение, которое позволяет создавать, изменять и управлять базами данных.

Пример: Книжный каталог в библиотеке — это база данных (книги, авторы, читатели). Программа, которая ищет книгу по запросу — это СУБД.

📖 2. Реляционная модель данных

В основе реляционной модели лежат таблицы (отношения). Каждая таблица состоит из:

  • Столбцов (атрибутов) — свойств объектов (например, Имя, Цена).
  • Строк (кортежей) — записей об объекте (конкретная книга или клиент).

Ключевые понятия:

  • Первичный ключ (PK) — уникальный идентификатор записи (например, ID студента).
  • Внешний ключ (FK) — ссылка на первичный ключ другой таблицы (связь между таблицами).
Пример связи: Таблица «Книги» имеет поле AuthorID, которое ссылается на поле ID в таблице «Авторы». Это связь «один ко многим».

📖 3. Типы связей между таблицами

Тип связиОписаниеПример
1:1Одна запись связана с однойЧеловек ↔ Паспорт
1:MОдна запись связана с несколькимиАвтор ↔ Книги
M:MМногие со многими (требуется связующая таблица)Студенты ↔ Курсы

🛠️ 4. Установка MS SQL Server и SSMS

Для работы нам понадобятся два компонента:

  1. SQL Server — сервер баз данных (движок).
    Скачать: SQL Server Express (бесплатно)
  2. SSMS (SQL Server Management Studio) — среда управления для написания запросов.
    Скачать: SSMS
⚠️ Важно: Устанавливайте SQL Server до SSMS. При установке выберите режим аутентификации "Смешанный режим" и установите пароль для пользователя sa.

🖥️ 5. Первое подключение к серверу через SSMS

  1. Запустите SSMS.
  2. В поле "Имя сервера" введите localhost или . (точка).
  3. Выберите "Проверка подлинности Windows" (если вы администратор компьютера).
  4. Нажмите "Подключиться".
Результат: Если вы видите папку "Базы данных" в обозревателе объектов — всё работает!

✍️ 6. Создание первой базы данных и таблицы

Откройте окно запроса (кнопка "New Query") и выполните следующий скрипт: 

-- Создаём новую базу данных
CREATE DATABASE FirstDB;
GO

-- Переключаемся на неё
USE FirstDB;
GO

-- Создаём таблицу Students
CREATE TABLE Students (
    ID INT PRIMARY KEY IDENTITY(1,1),
    [Name] NVARCHAR(50) NOT NULL,
    Age INT,
    [Group] NVARCHAR(10)
);
GO

-- Добавляем пару строк
INSERT INTO Students ([Name], Age, [Group])
VALUES 
    ('Анна Иванова', 19, 'ИС-21'),
    ('Петр Петров', 20, 'ПМ-22');
GO

-- Посмотрим результат
SELECT * FROM Students;
GO

После выполнения запроса вы увидите таблицу с двумя студентами.

📝 7. Задания для самостоятельной работы

Задание 1. Установка

Установите SQL Server Express и SSMS на свой компьютер. Сделайте скриншот окна SSMS с подключённым сервером.

Задание 2. Создание БД

Создайте базу данных LibraryDB. В ней создайте таблицу Books с полями: ID (PK), Title, Author, Year, Price.

Добавьте 3 книги (например, "Война и мир", "Преступление и наказание", "Мастер и Маргарита").

Напишите запрос, который выведет все книги дороже 500 рублей.

Задание 3. Дизайн

На листе бумаги или в любом редакторе нарисуйте ER-диаграмму для предметной области "Интернет-магазин" (таблицы: Товары, Категории, Заказы, Клиенты).
